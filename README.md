# CITY CRIME: ULTRA

Браузерная 3D-игра на Three.js и JavaScript.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

Репозиторий подключён к ChatGPT с правами чтения и записи. Исходники игры и настройка GitHub Pages будут добавлены следующим этапом.
